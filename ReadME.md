# svgcharts
This is a JS library for creating vector diagrams in HTML with animation using JS/CSS.

Currently, only doughnut and pie charts are implemented here.

Comparison with the [chart.js](https://www.chartjs.org) raster library:
|  parameter   | svgcharts.js | &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;chart.js&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |
| :----------- | :----------: | :----------:|
|vector scalable|✓|✕|
|quality in pdf|svg|png|
|animation|✓|✓|
|interactive|✓|✓|




## usage and examples

Open [github pages](https://alex-bayir.github.io/svgcharts/) to see interactive preview and usage code example.
